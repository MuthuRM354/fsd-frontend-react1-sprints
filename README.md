# FSD Frontend React 1 Sprints

Coursework repository for the Frontend React (Part 1) module of a Full Stack Developer (FSD) training program. Each subfolder is a standalone sprint exercise or project submission.

> **Note:** Every subfolder here is tracked as a bare git submodule reference (a gitlink with no corresponding entry in `.gitmodules`), so in this shallow clone the folders are present but empty on disk. The descriptions below are inferred from folder names, since the actual submission contents are not fetchable here.

## Contents

- `Assesment/fe-c5-assessment/` — Frontend Course 5 assessment submission.
- `Project/bake-my-cake-phase-1/` — Phase 1 of the "Bake My Cake" course project.
- `bake-my-cake-phase-1/` — Duplicate/alternate copy of the "Bake My Cake" phase 1 project.
- `sprint-1-pc1-react-fundamentals/` — Sprint 1 practice challenge: React fundamentals.
- `sprint-2-pc1-create-components/` — Sprint 2 practice challenge: creating React components.
- `sprint-3-pc1-manage-state/` — Sprint 3 practice challenge: managing state in React.
- `sprint-4-pc1-read-data/` — Sprint 4 practice challenge: reading/fetching data in React.
- `sprint-5-pc1-react-unit-testing/` — Sprint 5 practice challenge: unit testing React components.

## Tech Stack

- JavaScript
- React
- Node.js tooling for build/dev, per the repo's `.gitignore` (`node_modules/`, `dist/`, `build/`, `.next/`)

## Running the exercises

Each folder is a standalone React exercise or project, not part of a single build. In this clone the folders are empty placeholders (see note above); once populated with an actual submission:

- `cd <folder> && npm install && npm start`
